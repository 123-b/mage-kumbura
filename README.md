# Mage Kumbura

A simple offline Android app for recording rice-farming income and expenses.

## Features
- Record expense items and amounts
- Record income items and amounts
- Automatically calculate totals and profit/loss
- Save totals locally on the phone

## Build APK with GitHub
Upload this project to the repository's `main` branch. GitHub Actions will build a debug APK.
Open **Actions** → **Build Mage Kumbura APK** → latest successful run → **Artifacts** → download `mage-kumbura-debug-apk`.

The APK is an initial version. It stores totals locally and does not yet include date-wise reports, editing/deleting individual entries, backup, or cloud sync.
